# TOŪ — Arte & Ambientação Contemporânea

Portfólio e vitrine digital da **TOŪ**, desenvolvida para destacar peças exclusivas de decoração e arte contemporânea com uma experiência visual imersiva e minimalista.

## 🛠️ Tecnologias Utilizadas

* **React** + **Vite**[cite: 9] — Performance e velocidade de carregamento ultrarrápidas.
* **TypeScript** — Segurança e robustez na arquitetura do código.
* **Tailwind CSS** — Estilização moderna e responsiva.
* **Lucide React** — Ícones minimalistas para interface.

## 🚀 Como Executar Localmente

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado na sua máquina. No terminal, execute os seguintes comandos[cite: 9]:

```bash
# Instalar as dependências
npm install

# Iniciar o servidor de desenvolvimento local
npm run dev
